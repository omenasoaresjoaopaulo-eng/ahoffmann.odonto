# Blog Odonto

Este blog foi criado para o perfil de Instagram da Ana Cassia Hoffmann, estudante de Odontologia em Sinop-MT.

## Como usar

1. Abra o terminal no VS Code: `Terminal` > `New Terminal`
2. Entre na pasta do projeto:
   - `cd /workspaces/ahoffmann.odonto`
3. Abra um servidor local para ver o site no navegador:
   - `python3 -m http.server 8000`
4. Use o painel `Ports` do Codespaces para abrir a porta `8000`.
5. Clique no link gerado para ver o blog.

## Arquivos do blog

- `index.html` — página inicial do blog
- `sobre.html` — página sobre o perfil
- `style.css` — estilos do site
- `posts/dicas-de-escovacao.html` — post de exemplo
- `posts/planejamento-de-tratamento.html` — post de exemplo

## Como editar

- Abra `index.html` para mudar o texto da página inicial.
- Abra `sobre.html` para editar a apresentação do perfil.
- Abra os arquivos em `posts/` para alterar os posts ou criar novos.
- Salve com `Ctrl+S` e atualize o navegador.
